先算清楚：12 MHz 为什么是 1 微秒一个机器周期？

板子晶振是 12 MHz，意思是每秒振荡 1200 万次，所以一个时钟节拍是 1 ÷ 12,000,000 s ≈ 0.0833 μs。传统 12T 8051 要用 12 个时钟节拍完成一个机器周期，因此：0.0833 μs × 12 ≈ 1 μs。

void delay(unsigned int t)
{
    unsigned int i,j;
    for(i=0; i<t; i++)
        for(j=0; j<120; j++);
}

j=120 表示每次外层循环都空转 120 次；总内层次数是 t × 120。每轮还包含比较、跳转、自增等指令，课堂可先按约 4 个机器周期，即约 4 μs/轮估算。

while(i--)：没有 120 时，真实秒数怎么得出？
void delay(unsigned int i)
{
    while(i--);

i-- 先判断旧值，再减 1。i=3 时判断 3、2、1、0，循环体执行 3 次。这里确实没有 j=120；循环次数就是传入的 i，例如 delay(40000) 大约执行 40000 轮。

要换算真实秒数，必须知道“每轮 while 编译成多少机器周期”。这个数字不能只看 C 代码，应该在 Keil 编译后看汇编指令；下方计算器中的“每轮周期”只是课堂假设值，改成 Keil 反汇编统计值后才是对应估算。精确值还要以芯片 12T/6T 设置和示波器测量为准。

从 delay 到 LED 多久变化一次

12 MHz、12T 板子先记住：1 机器周期 ≈ 1 μs。双层 for 的估算是 t × 120 × 每轮机器周期 × 1 μs；delay(300) 若按 4 周期/轮作课堂示例，约为 300×120×4 μs=0.144 s，所以亮灭切换约每 0.144 秒一次，完整亮灭周期约 0.288 秒。

while 版本没有 120，使用 i × 每轮机器周期 × 1 μs。例如 delay(40000) 若按假设的 2 周期/轮，约为 0.08 秒；实际值请把 Keil 反汇编统计出的周期填入计算器，不能直接把 0.08 秒当成所有编译器都一样。

项目三：按键计数

每按下一次 S2（P3.4），计数加 1；松开后等待下一次按键，避免一次长按重复计数。

00
P1.0 = 1（松开） · 等待按下
拆解步骤
  1. 读取 S2（P3.4），按下时输入为 0。
  2. 检测到下降沿后只加 1 次。
  3. 松开后等待下一次按下。
#include <reg52.h>
unsigned int count = 0;
sbit S2 = P3^4;
void delay_ms(unsigned int t){ unsigned int i,j; for(i=0;i<t;i++) for(j=0;j<120;j++); }
void main(){
  while(1){
    if(S2 == 0){ delay_ms(10); if(S2 == 0){ count++; while(S2 == 0); } }
    P0 = count % 10;
  }
}

关键是“按下确认 → 只加一次 → 等待松开”。真实板上可把 count 拆成个位、十位，再送给数码管段码表。

对应说明书中的“按键计数”：计数结果由数码管显示。

项目四：4×4 矩阵键盘

矩阵键盘的 8 根线接 P1.0～P1.7。点击按键，观察行列扫描得到的键值。

等待按键
行线/列线均为高电平 1
拆解步骤
  1. 依次把一行拉低。
  2. 读取四根列线是否出现低电平。
  3. 行号和列号组合成键值。
#include <reg52.h>
unsigned char key_scan(void){
  unsigned char row;
  for(row=0; row<4; row++){
    P1 = (unsigned char)~(1 << row);
    if((P1 & 0xF0) != 0xF0){ delay_ms(10); return (row << 2) | ((~P1 >> 4) & 0x0F); }
  }
  return 0xFF;
}
void main(){ unsigned char key; while(1){ key=key_scan(); if(key!=0xFF) P0=key; } }

矩阵键盘不是同时读 16 个按键，而是逐行拉低、读取列线；行号和列号合成一个键值。

课堂讲解重点：逐行拉低，再读取列线；检测到低电平后完成消抖。

项目五：定时器、中断与六位数码管

先用数码管理解段码和位选，再用项目五 PPT 中的定时器 0 中断替代长时间 Delay。

000000
P0 段码：等待扫描；74HC138：等待位选。
数码管动态显示代码
  1. P0 先输出当前数字的段码。
  2. 74HC573 锁存段码。
  3. 74HC138 选择一位，快速轮询六位。
#include <reg52.h>
unsigned char code seg_code[10]={0xC0,0xF9,0xA4,0xB0,0x99,0x92,0x82,0xF8,0x80,0x90};
void delay_ms(unsigned int t){ unsigned int i,j; for(i=0;i<t;i++) for(j=0;j<120;j++); }
void main(){
  unsigned char i, digit[6]={9,0,1,2,2,5};
  while(1){ for(i=0;i<6;i++){ P0=seg_code[digit[i]]; P2=(0xFE<<i); delay_ms(2); } }
}

每位只点亮约 2 ms，靠快速轮询形成连续视觉；0xC0 等是共阳数码管的低电平有效段码。

项目五延伸：定时器 0 中断，让 LED 定时翻转
  1. TMOD=0x01：定时器 0 工作在 16 位模式 1。
  2. ET0、EA 开中断，TR0 启动定时器。
  3. 中断服务函数重装初值并翻转 LED。
#include <reg52.h>
sbit LED = P1^0;
void Timer0Init(void){ TMOD=0x01; TH0=(65536-50000)/256; TL0=(65536-50000)%256; ET0=1; EA=1; TR0=1; }
void Timer0_ISR(void) interrupt 1{ TH0=(65536-50000)/256; TL0=(65536-50000)%256; LED=~LED; }
void main(void){ Timer0Init(); while(1){} }

定时器像“小闹钟”：主循环可以空转，时间到后由中断服务函数完成定时任务。教学时可把 50 ms 中断累计 60 次，实现约 3 秒翻转。

仿真用于理解“段码 + 位选 + 快速轮询”；真实板上由 74HC573 和 74HC138 完成驱动。

KEIL C51 · STC-ISP · TX-1C 实操

实操教程：从 C 代码到开发板运行

跟着图文流程，把课堂仿真代码编译成 HEX，再下载到 STC89C52RC。每一步都标出“为什么这样做”。

1建立工程2添加源文件3输入代码4配置 HEX5Build 编译6查看结果7打开 STC-ISP8打开 HEX9下载运行
先分清两件事：编译是把 C 源程序交给 Keil，生成单片机能识别的 HEX 文件；下载是把 HEX 写入芯片程序存储器。下载完成并重新上电或复位后，单片机才开始执行。

建立工程文件

在 Project → New uVision Project 中选择项目文件夹，并填写工程名。文件夹建议与课堂项目同名，便于找到 HEX。

选择芯片型号

选择与开发板完全一致的 STC89C52RC 型号，并接受复制启动文件提示。

新建 C 源文件

第一个 New：File → New，新建 C 源文件并保存为 LED.c。

把源文件加入工程

第二个 New：右键 Source Group 1，选择 Add New Item... 新建并加入 C 源文件。

输入并检查代码

在编辑器粘贴 C51 程序，先确认 P1.0～P1.7 与板上 LED 的连接关系。

勾选生成 HEX

Options for Target → Output，填写输出名并勾选 Create HEX File。

Build 编译

点击 Build Target 或按 F7；先看底部 Build Output，再处理红色错误行。

读懂编译结果

看到 0 Error(s)、0 Warning(s) 和 creating hex file，才说明 HEX 已生成。

打开下载软件

连接 USB 下载线并给实验板上电，启动 STC-ISP，选择对应 MCU 和串口。

打开 HEX 文件

点击打开程序文件，进入 Keil 工程的 Objects 文件夹，选择生成的 .hex。

下载并运行

点击下载/编程，按软件提示给板子重新上电；完成后 LED 会按程序运行。

排错与复盘

没有 HEX 多半是未勾选 Create HEX；下载失败先检查串口、芯片型号和上电顺序。

下载完成后的确认

查看 STC-ISP 的完成信息，关闭下载器后让开发板复位，观察 P1 LED 是否与程序节拍一致。

项目一至项目五：头文件怎么选

  • STC89C52RC.H：开发板芯片专用寄存器定义，优先用于 STC89C52RC 工程。
  • REG51.H 或 REG52.H：传统 51 兼容寄存器定义；如果老师发的工程模板指定了其中一个，就保持模板一致。
  • INTRINS.H：Keil C51 内部函数库，提供 _crol_() 循环左移、_cror_() 循环右移等函数。
  • 项目一 P1 流水灯会用到芯片头文件 + INTRINS.H；项目二至项目五至少需要芯片头文件，定时器项目还要使用定时器/中断寄存器定义。
